# 上海应届生落户测算

面向应届毕业生的上海落户通道指引与模拟评分工具，使用 2026 年官方政策口径。

在线访问：[上海应届生落户测算](https://bingneko77.github.io/shanghai-hukou-score/)

## 适用通道

- 国内普通高校非上海生源毕业生：基本条件、直接落户线索和 72 分模拟评分。
- 上海生源或已有上海居民常住户口：户籍迁回或市内迁移方向及官方来源。
- 拟使用国（境）外学历的留学回国毕业生：现行留学回国人员政策及官方办理指南。
- 不确定：先核对学校认定的生源信息、户口性质及拟使用学历。

非上海生源不按大学所在地判断。上海高校的外省生源、仅因就学迁入上海学生集体户的毕业生，不能据此改按上海居民户籍通道处理。不同通道不共用 72 分标准。

## 使用

直接打开 `index.html` 或访问在线网址，无需安装依赖。网页不上传、不保存所填个人信息。学校与专业须准确识别；人工学校类别仅用于试算，不自动产生直接落户资格。

专业数据按研究生、本科及职业本科目录分层，包含官方附录 5 的 361 条记录。职业本科目录不表示专科学历具备本科申报资格。

结果仅供政策模拟，不代表官方审核或当前仍可申报。页面显示 2026 年申报时效；西部计划等须按毕业当年规则另行核验。
